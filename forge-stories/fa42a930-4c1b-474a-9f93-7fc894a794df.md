# Feature: Delete Task (Test1)

## Goal
Allow users to delete a task permanently. The Express API gains a `DELETE /tasks/:id` route; the Next.js frontend exposes a Delete button per task row that calls it and refreshes the list.

---

## Tasks

### 1. API — `src/api/index.js`
Add a new route handler **after** the existing PATCH handler:

```js
// DELETE /tasks/:id — delete a task
app.delete('/tasks/:id', async (req, res) => {
  const id = parseInt(req.params.id, 10);
  const { rows } = await db.query('DELETE FROM tasks WHERE id = $1 RETURNING id', [id]);
  if (rows.length === 0) return res.status(404).json({ error: 'Not found' });
  res.status(204).end();
});
```

- Parse `id` from `req.params.id` as an integer.
- Run `DELETE … RETURNING id` so a missing row returns 0 rows → 404.
- Return **204 No Content** on success (no body).

---

### 2. Server action — `src/web/app/actions.ts`
Add a new exported async function below `toggleTask`:

```ts
export async function deleteTask(id: number) {
  await fetch(`${API_URL}/tasks/${id}`, { method: 'DELETE' });
  revalidatePath('/');
}
```

---

### 3. UI — `src/web/app/page.tsx`

1. Import `deleteTask` alongside the existing imports.
2. Inside the `tasks.map(...)` list item, add a delete `<form>` after the toggle form:

```tsx
<form
  action={async () => {
    'use server';
    await deleteTask(task.id);
  }}
>
  <button
    type="submit"
    className="ml-auto text-zinc-400 hover:text-red-500 transition-colors"
    aria-label="Delete task"
  >
    {/* × icon */}
    <svg viewBox="0 0 12 12" className="w-4 h-4" fill="none" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round">
      <path d="M2 2l8 8M10 2l-8 8" />
    </svg>
  </button>
</form>
```

3. The `<li>` flex row already uses `items-center gap-3`, so the button naturally aligns to the right when `ml-auto` is applied.

## Acceptance Criteria

| # | Scenario | Expected result |
|---|----------|-----------------|
| 1 | `DELETE /tasks/1` on an existing task | `204 No Content`, task gone from `GET /tasks` |
| 2 | `DELETE /tasks/999` on a non-existent task | `404 { "error": "Not found" }` |
| 3 | Clicking the × button in the browser | Task disappears from the list immediately (page revalidates) |
| 4 | All existing routes (`GET`, `POST`, `PATCH`) | Unchanged behaviour |
| 5 | Empty task list after last deletion | "No tasks yet." placeholder renders |
