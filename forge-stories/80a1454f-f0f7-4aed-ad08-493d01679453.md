# Story: Add "Restart only the API service" subsection to README.md

## Goal
Insert a short operational subsection into the existing `## Running locally with Docker Compose` section so that developers know they can restart just the API container with `docker compose restart api` — without touching `web` or `postgres` — and understand that restarting is distinct from rebuilding the image.

---

## Task

### Edit `README.md` (repository root)

**Exact insertion point:** After the closing line of `### Rebuild after code changes` and before the `### Inspect local service logs` heading.

**Content to insert:**

```markdown
### Restart only the API service

To restart just the API container without affecting the other services:

```bash
docker compose restart api
```

This restarts only the `api` service. The `web` and `postgres` (database) services continue running undisturbed and do not need to be restarted. Note that restarting a service is distinct from rebuilding its image — use `docker compose up --build api` if you need to rebuild the image first.
```

**Nothing else changes:** every other line in `README.md` must be preserved verbatim — headings, code blocks, tables, links, and all other subsections.
