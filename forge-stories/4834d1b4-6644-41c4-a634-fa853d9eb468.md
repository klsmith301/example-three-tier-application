# Remove DELETE Endpoint

## Goal
Remove permanent task deletion functionality from the API and frontend, simplifying the application to only support task creation, reading, and toggling completion status.

## Tasks

### 1. Remove DELETE endpoint from API (`src/api/index.js`)
- Delete lines 49–55 (the `app.delete('/tasks/:id', ...)` handler)
- This removes the HTTP DELETE route permanently

### 2. Remove deleteTask server action (`src/web/app/actions.ts`)
- Delete lines 35–38 (the `deleteTask(id: number)` function)
- Update the import statement to remove `deleteTask` from exports

### 3. Remove delete button UI from frontend (`src/web/app/page.tsx`)
- Remove line 1 import of `deleteTask` from `./actions`
- Delete lines 86–97 (the delete button form with trash icon SVG)
- Keep the checkbox form and task display intact

## Acceptance Criteria
- [x] API no longer has a DELETE route for tasks
- [x] Frontend no longer exports or calls the `deleteTask` function
- [x] No delete button appears in the UI
- [x] Application still builds and runs with `docker compose up --build`
- [x] GET, POST (add task), and PATCH (toggle complete) endpoints still work
- [x] No broken imports or references to `deleteTask` remain
