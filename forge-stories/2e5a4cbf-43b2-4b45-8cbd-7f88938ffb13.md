## Goal
Prepend a single descriptive sentence and a blank line to the top of `README.md`, open a pull request for review, and leave everything else untouched.

---

## Tasks

### 1. Edit `README.md`
**File:** `README.md`

Insert two new lines **before** the current line 1:

```
This repository demonstrates an example three-tier application.

# example-three-tier-application
…
```

- Line 1 (new): `This repository demonstrates an example three-tier application.`
- Line 2 (new): *(empty)*
- Line 3 onwards: every existing line of the file, byte-for-byte unchanged.

No other files are modified.

---

## Acceptance criteria

1. `README.md` line 1 is exactly `This repository demonstrates an example three-tier application.` (no leading/trailing spaces, Unix LF line ending).
2. `README.md` line 2 is a blank line (empty, Unix LF).
3. `README.md` line 3 is `# example-three-tier-application` — the original first line.
4. All subsequent lines are identical to the original file.
5. `git diff --check` reports no whitespace errors on the diff.
6. No other file in the repository is modified.
7. Change is submitted as a pull request; the branch is **not** merged.
